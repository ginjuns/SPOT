# 사용자 테스트 진행 안내와 설문지

명세서 12장 4주차 3단계(사용자 테스트, 설문)와 13장 성과 목표 두 가지를 확인하기 위한 자료다.

| 확인할 것 | 묻는 방법 | 목표 |
|---|---|---|
| 새로 알게 된 혜택 수 | 설문 2번 | 참가자 1인당 1개 이상 |
| 사용 편의성 | 설문 3~6번 (5점 척도), 60대 이상 참가자 | 평균 4점 이상 |

## 1. 준비

- **참가자**: 5명 이상, 그중 **60대 이상 3명 이상**. 가족·이웃·경로당·주민센터에서 부탁한다.
- **기기**: 참가자 본인 휴대폰이 가장 좋다. 어려우면 진행자 휴대폰을 쓴다.
- **시작 10분 전에 배포 주소에 미리 접속**해 둔다 (무료 서버는 15분쯤 쉬면 잠들고, 깨어나는 데 1분쯤 걸린다).
- **하루 질문 한도**: 한 사람당 30회, 서비스 전체 200회다. 테스트하는 날에는 답변 평가(`eval_scenarios.py`)를 돌리지 않는다.
- 설문지를 참가자 수만큼 인쇄한다. 글씨를 읽기 어려운 분께는 진행자가 읽어 드리고 받아 적는다.

## 2. 참가자에게 먼저 드릴 말씀

> 정부나 시·군·구에서 주는 지원을 찾아 주는 서비스를 만들고 있어요. 한번 써 보시고 느낀 점을 알려 주시면 됩니다.
> 시험이 아니에요. 잘 안 되는 부분이 있으면 서비스가 부족한 것이니 편하게 말씀해 주세요.
> 이름이나 전화번호는 입력하지 않으셔도 됩니다. 입력하신 내용은 저장하지 않아요.

## 3. 진행 순서 (한 사람당 10~15분)

진행자는 **먼저 도와주지 않는다.** 30초 넘게 멈추거나 도와 달라고 할 때만 돕고, 도운 곳을 관찰 기록에 적는다.

| 순서 | 참가자가 할 일 | 진행자가 볼 것 |
|---|---|---|
| 1 | 시작 화면에서 "분야로 찾기"의 버튼 하나를 눌러 본다. (예: 병원·건강) | 무엇을 눌러야 할지 바로 아는가, 분야 이름을 이해하는가 |
| 2 | 결과 화면에서 [내 조건 고르기]를 눌러 나이대와 사는 지역을 고른다. | 버튼의 말을 이해하는가, 시·군·구를 찾는가, 단계를 끝까지 가는가 |
| 3 | 결과 카드를 읽고, 하나를 골라 [자세히 보기]를 누른다. | 한 줄 요약을 이해하는가, 신청하는 곳을 찾는가 |
| 4 | [처음으로]로 가서, 들어 본 지원 이름을 검색창에 적어 찾아본다. (떠오르지 않으면 "기초연금") | 글자를 입력할 수 있는가, 찾던 것이 위쪽에 나오는가 |
| 5 | 오른쪽 아래 [말로 묻기] 버튼을 눌러, 요즘 걱정되는 일을 평소 말투로 물어본다. (떠오르지 않으면 예시 질문 버튼을 누른다) | 버튼을 알아보는가, 되묻는 버튼을 고르는가, 답을 이해하는가 |
| 6 | 채팅 결과 아래의 [가족에게 공유]를 눌러 본다. | 공유가 되는가 |
| 7 | (글씨가 작다고 하면) 시작 화면의 큰 글씨 버튼을 안내한다. | 켠 뒤에 읽기 편해졌는가 |
| 8 | 설문지를 작성한다. | — |

### 관찰 기록 (진행자가 참가자마다 적는다)

| 항목 | 기록 |
|---|---|
| 참가자 번호 / 나이대 | |
| 쓴 기기 (본인 휴대폰 / 진행자 휴대폰) | |
| 도움이 필요했던 곳 (순서 번호와 내용) | |
| 끝까지 혼자 한 순서 | |
| 참가자가 한 말 중 기억할 것 | |
| 화면이나 답변에서 이상했던 것 | |

**참가자가 입력한 질문 문장은 적지 않는다.** 필요하면 "병원비 질문"처럼 분야만 적는다.
