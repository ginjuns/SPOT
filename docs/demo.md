# 시연 순서 (2026-11-23 배포 주소에서 리허설함)

배포 주소: https://spot-0eg5.onrender.com

## 시연 10분 전
- 휴대폰과 노트북에서 배포 주소를 열어 둔다. 무료 서버는 15분쯤 쉬면 잠들고, 깨어나는 데 1분쯤 걸린다.
- 주소 끝에 `/api/health`를 붙여 `{"status":"ok", ...}`가 나오는지 본다.
- 학교 와이파이가 안 될 때를 대비해 휴대폰 핫스팟을 켜 둔다.
- 아래 순서를 한 번 녹화해 둔다 (인터넷·Groq가 안 될 때 보여 줄 영상).

## 순서 (10분 안팎)
1. **시작 화면**: 큰 글씨, 분야 버튼 10개, 검색창. [크게] 버튼으로 글씨를 키워 보인다.
2. **낱말로 찾기**: 검색창에 "난방비" → 에너지바우처가 나온다 ("비슷한 말로도 찾았어요" 안내).
3. **조건으로 좁히기**: 75세 이상 · 서울 강남구 · 혼자 살아요 → 강남구·서울시 정책이 먼저 나온다.
4. **정책 상세**: 기초연금 → 신청 기간, 준비할 서류, 문의처 전화, [소리로 듣기], [주민센터에서 보여주기].
5. **물어보기 (채팅)**: 아래 질문 중 2~3개. 처음에 나이대·지역 버튼을 고르면 그다음부터는 묻지 않는다.
6. **이어서 묻기**: 결과를 본 뒤 "서류는 뭐가 필요해요?" → 방금 본 정책의 서류가 바로 나온다 (AI 안 씀).
7. **가족에게 공유**: 링크로 같은 결과를 볼 수 있다.

## 채팅에 쓸 질문 (75세 · 서울 강남구로 3번씩 돌려 매번 같은 답이 나온 것)
| 질문 | 나오는 정책 | 보여 줄 점 |
|---|---|---|
| 나라에서 노인들한테 매달 주는 돈 있잖아요. 나도 받을 수 있나요? | 기초연금 | 정책 이름을 몰라도 찾는다 |
| 혼자 사는데 밤에 쓰러지기라도 하면 아무도 모를까 봐 무서워요 | 응급안전안심서비스, 노인맞춤돌봄 | 상황만 말해도 서비스를 찾는다 |
| 요즘 자꾸 깜빡깜빡해서 혹시 치매인가 싶어요. 검사를 돈 안 들이고 받을 수 있나요? | 치매검진, 치매안심센터 | |
| 무릎 연골이 다 닳아서 수술해야 한대요. 수술비 도와주는 데가 있을까요? | 노인 무릎인공관절 수술 지원 | 1초 안에 답 (자주 묻는 질문, AI 안 씀) |
| 영화 한 편 보고 싶은데 돈이 없어요 | 문화누리카드 | 복지 밖 분야도 찾는다 |
| 연탄 때는디 연탄값 도와주는거 잇나 | 연탄쿠폰, 에너지바우처 | 사투리·맞춤법이 틀려도 알아듣는다 |

채팅 첫 화면의 예시 버튼 중 하나를 "혼자 사는데 밤에 쓰러지기라도 하면…"으로 바꿨다 (예전 "허리가 아파서 병원에…"는 일반 의료비 정책만 나와서 인상이 약했다).

## 질문이 나오면
- **정확도**: 처음 보는 어르신 말투 질문 60개를 실제와 똑같이 돌려 채점하면 정확 77%, 부분 13%, 틀림 10%. 없는 정책을 지어낸 것은 0건 (카드 내용은 모두 공공데이터 원문, AI가 쓴 것은 한 줄 요약뿐).
- **AI가 안 되면?**: 직접 찾기(낱말·분야·조건)는 AI를 쓰지 않아서 항상 된다. 채팅은 "버튼으로 찾아 볼까요?"로 넘어간다.
- **개인정보**: 로그인 없음, 대화는 저장하지 않음, 전화번호·주민번호는 AI에 보내기 전에 가린다.
- **비용**: 모두 무료 (Render, Neon, Groq 무료 한도, 공공데이터포털).
- **자격 판단**: 하지 않는다. 소득 기준이 있는 정책은 "소득 기준 있음" 표시 후 복지로 모의계산·주민센터로 안내한다.
